# VK Lite 0.2.0

Отдельный облегчённый веб-клиент-макет ВКонтакте. Этот репозиторий изолирован от `kesug-slots/kesug-slots`: здесь нет файлов Kesug Slots.

## Загрузка в GitHub

1. На GitHub под аккаунтом `kesug-slots` создай **новый пустой репозиторий** с именем `VK-Lite`.
2. Не добавляй при создании README, `.gitignore` или лицензию — всё нужное уже находится в этом архиве.
3. Распакуй ZIP и загрузи **содержимое папки** `VK-Lite-Repository` в корень нового репозитория `kesug-slots/VK-Lite`.
4. Открой `Settings → Pages` и выбери `GitHub Actions` в разделе Build and deployment.
5. Открой вкладку `Actions`. Workflow `Deploy VK Lite to GitHub Pages` соберёт и опубликует сайт после push в ветку `main`.

Ожидаемый адрес проекта: `https://kesug-slots.github.io/VK-Lite/`.

## Локальный запуск

Требуется Node.js 22 или новее.

- Windows: дважды нажми `START.bat`.
- Или в терминале выполни `npm install`, затем `npm run dev`.

## Подключение VK ID

После публикации:

1. Создай Web-приложение в официальном кабинете VK ID: https://id.vk.ru/about/business/go
2. Базовый домен для ожидаемого адреса Pages: `kesug-slots.github.io`.
3. В VK Lite открой `Настройки → Подключение VK ID`, скопируй показанный Redirect URL и добавь его в доверенные Redirect URL приложения VK ID.
4. Вставь числовой APP ID в VK Lite и сохрани его.
5. Нажми `Войти через VK ID`.

Если фактический GitHub Pages URL отличается, используй точный URL из адресной строки. Redirect URL в VK ID должен совпадать с адресом, который отображает VK Lite.

В проекте используется официальный пакет `@vkid/sdk` и OAuth 2.1 Authorization Code + PKCE. Секретный ключ нельзя помещать в клиентский код или GitHub. Токены не записываются в `localStorage`; базовая информация аккаунта загружается через VK ID SDK. Подключение VK ID само по себе не предоставляет доступ ко всем данным ВКонтакте. Лента, сообщения, друзья и другие разделы остаются демо до отдельной интеграции с разрешёнными методами VK API.

## Состав проекта

- `index.html` — приложение.
- `src/` — интерфейс и логика.
- `public/` — иконка, PWA manifest, service worker.
- `.github/workflows/deploy.yml` — автоматическая публикация на GitHub Pages.
- `preview.html` — автономное превью макета без авторизации.

## Производительность

Нет автозапуска видео, тяжёлых внешних шрифтов и декоративных библиотек. Анимации можно уменьшить в настройках. На iPhone и Android можно добавить сайт на главный экран через меню браузера.

VK Lite — независимый неофициальный клиент и не является приложением, разработанным или одобренным VK.
